# Desarrollo Móvil UPQ

Repositorio académico que reúne las prácticas, tareas, ejercicios y proyectos
realizados durante el curso de Desarrollo Móvil en la UPQ.

## Proyectos

- [Coffee Code](Coffee-code/README.md): tienda web modular de productos, pedidos, Cliente, Cocina y Caja.
- [Introducción a JavaScript](Intro-JS/README.md): ejercicios de lógica en navegador y ejecución con Node.js.
- [Pruebas de Git](prueba-Git/README.md): actividad de perfil, apuntes y práctica inicial de Git.

## Descripción

Este repositorio funciona como evidencia del aprendizaje y de la aplicación de
los conocimientos adquiridos durante el cuatrimestre. Cada proyecto cuenta con
su propia documentación, objetivos, estructura y forma de ejecución.

## Vista general

| Proyecto                             | Tecnologías principales        | Propósito                             |
| ------------------------------------ | ------------------------------ | ------------------------------------- |
| [Coffee Code](Coffee-code/README.md) | HTML, CSS, JavaScript, Node.js | Construir una tienda web funcional.   |
| [Intro-JS](Intro-JS/README.md)       | HTML, JavaScript, Node.js      | Practicar fundamentos de JavaScript.  |
| [prueba-Git](prueba-Git/README.md)   | HTML y Git                     | Realizar pruebas y registrar apuntes. |

## Tecnologías y conceptos practicados

- HTML5 y estructura semántica.
- CSS3 y diseño responsive.
- JavaScript y módulos ES (`.mjs`).
- Funciones, arreglos y objetos.
- `map()`, `forEach()`, `filter()`, `find()` y `reduce()`.
- Desestructuración de objetos.
- Eventos y manipulación del DOM.
- Persistencia con `localStorage`.
- Node.js y servidor HTTP local.
- Git y control de versiones.
