# Pruebas de Git

Actividad inicial para practicar la organización de archivos, la creación de
una página HTML y el registro de apuntes relacionados con Git.

## Archivos

| Archivo       | Descripción                                        |
| ------------- | -------------------------------------------------- |
| `index.html`  | Página HTML con un perfil y una descripción breve. |
| `apuntes.txt` | Espacio para notas y observaciones de la práctica. |

## Actividades

- Crear y modificar archivos dentro de un proyecto.
- Organizar el contenido en una carpeta independiente.
- Practicar la creación de cambios para registrarlos con Git.
- Documentar observaciones en un archivo de texto.
- Comprobar el resultado de una página HTML en el navegador.

## Ejecutar la página

Desde la raíz del repositorio, inicia un servidor local:

```bash
python -m http.server 8000
```

Después abre:

```text
http://localhost:8000/prueba-Git/index.html
```

También puede utilizarse Live Server desde VS Code.
